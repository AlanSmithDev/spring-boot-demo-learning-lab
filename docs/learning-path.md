# spring-boot-demo-learning-lab 学习路径

本仓库整理自 xkcoding/spring-boot-demo（MIT），用于系统学习。

## 阶段一：建立全局认知
- 阅读本文件与 README.md，理解项目定位与解决的问题。
- 浏览顶层模块，建立「整体由哪几块组成」的地图。

## 阶段二：核心模块精读
- 按依赖关系从底层向上阅读核心实现。
- 每个模块都为独立提交，可 `git show` / `git log` 对照。

## 阶段三：动手实践
- 参照原项目 README.en.md 官方用法跑通最小示例。
- 尝试修改一个小功能，验证理解。

## 阶段四：总结输出
- 输出自己的笔记 / 脑图，形成可复用知识。
